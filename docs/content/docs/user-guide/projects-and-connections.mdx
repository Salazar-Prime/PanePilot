## Connections

PanePilot creates a built-in local connection with the stable ID `local` and the display
name **This Mac**. At startup it reads `~/.ssh/config` and adds one connection for each
concrete `Host` alias. An SSH connection has an ID in the form `ssh:<alias>`.

Projects are grouped under their connection in the sidebar. Empty SSH groups are hidden;
the local group remains visible so the first project can be created.

Connection context actions include:

- Create a project on that connection.
- Test an SSH connection.
- Manage saved port forwards for an SSH connection.
- Copy the corresponding `ssh <alias>` command.

## Project identity

Every project has:

- A stable UUID.
- A `terminal` or `latex` type.
- A display name.
- One connection and one folder on that connection.
- Optional repository URL metadata.
- Aggregate state, archive state, and timestamps.

A name is presentation, not identity. Renaming a project changes neither its UUID nor
its location.

## Local and remote creation

Local and remote creation can attach an existing folder or create one new folder under
an existing parent. Local parent selection uses the operating system's directory
chooser. Remote selection starts in the SSH user's home directory and shows
subdirectories. In both cases, the new folder accepts one validated name, refuses an
existing destination, and supplies the default editable project name. PanePilot shows
the final destination before creating it. New LaTeX folders also receive the configured
main `.tex` file with a minimal document.

Remote paths are canonicalized before they are stored. Creating a folder on an SSH
connection uses the same bounded remote file operation as the Files workspace.
The SSH picker keeps the editable path, new-folder control, and folder/file listing in
one browser. Typing after the current path fuzzy-filters and ranks the entries already
shown below it. Selecting a folder navigates into it; files remain visible for context.
The best folder match is selected first. Use the arrow keys to change the selection,
Tab to complete it in the path, or slash/Enter to open it. A slash after each fuzzy
path segment therefore navigates through the remote tree one verified folder at a
time.

The remote browser requires `python3` on the host. PanePilot sends a small base64-wrapped
Python script over SSH and exchanges JSON over standard input and output.

## Project actions

Depending on connection and repository metadata, a project menu can:

- Open the project.
- Rename it.
- Open its capabilities or start a terminal.
- Open its local folder in Finder.
- Open its repository URL or read-only Git pane.
- Copy its local path or `<ssh-alias>:<remote-path>`.
- Archive it.

Git status and history work for local and SSH project folders. A GitHub `origin` can
also show Public, Private, Internal, or Unknown visibility without changing the remote.

## Archiving projects

Archiving first stops every exact live terminal and capability-chat backend, including
detached or hidden tmux sessions. The project is archived only after every stop
succeeds.

Archiving:

- Hides the project from live connection groups.
- Moves it to **Archived projects**.
- Excludes it and its terminals from live status counts.
- Preserves terminals, output, activity, files, and provider-owned archives.

Restoring returns the project to normal navigation. **Remove permanently** can then
delete the archived project's local SQLite workspace records after confirmation. It
never deletes the project folder, `.panepilot` metadata, or provider archives.
