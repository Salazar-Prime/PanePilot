PanePilot brings local projects, SSH workspaces, persistent terminals, coding-agent
attention, files, provider chat archives, and project activity into one desktop window.
The package is still named `project-console`, but the product name is PanePilot.

## What exists today

The current application supports **terminal projects** and section-aware **LaTeX
projects**. Each project is tied to one folder and one local or SSH connection. SSH
connections come from concrete aliases in `~/.ssh/config`.

Within a project, PanePilot provides:

- Multiple terminal sessions with distinct login-shell, Codex, and Claude Code
  profiles.
- Editable Actions for reusable commands, with fresh ephemeral runs and latest-output
  retention.
- Project-scoped Quick Codex chats and, for LaTeX projects, scoped writing chats.
- tmux-backed persistence when tmux is available, with a plain PTY fallback.
- Direct terminal jumps from both the sidebar and workspace tabs.
- Pinning, manual tab ordering, rename, detach, reload, transfer, and permanent
  deletion workflows.
- Exact Codex conversation identity and restart through `codex resume <session-id>`.
- Local and remote file browsing, Markdown preview, file/folder creation, rename,
  download, and explicit Monaco-based editing.
- Read-only search across local and remote Codex and Claude conversation archives.
- A project activity timeline, read-only Git pane, and cross-project attention counts.
- LaTeX manuscript mapping, source editing, proof comments, PDF preview, compile, and
  native macOS PDF printing.
- SSH connection tests and loopback-only SSH port forwards.

## Current release boundary

This documentation describes the v0.12.0 source. PanePilot uses tmux pane-title
metadata for current remote Codex state and screen-based detection as a fallback.
Provider archives remain provider-owned and are indexed read-only.

## Product shape

PanePilot is intentionally a single desktop UI:

| Region | Responsibility |
| --- | --- |
| Top bar | Project type, selected project identity, repository state, pinned actions, and overflow |
| Left sidebar | Connections, projects, terminals, state, and direct navigation |
| Main workspace | Type-specific tools including Terminals or Manuscript, Files, chats, and Activity |
| Bottom status bar | Focused-project tools plus cross-project agent and attention totals |

The application is not a general terminal multiplexer. It uses terminal sessions as a
project capability and adds project identity, agent-oriented state, provider archives, files,
and remote operations around them.
