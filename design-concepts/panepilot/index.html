▣ PanePilot / Interface studies

Five ways to make room
for the work.

These are browser-only layout studies based on your current PanePilot screen. The project sidebar, terminal, and bottom status counts remain the anchors; each concept changes how the layers between them are organized.

How to compareOpen any concept, switch a terminal tab, try a project view, and click a status count. Use the “All concepts” link to return here.
01 / COMPASS

Compass

A cleaner evolution of today’s layout. Stronger active-session identity, quieter global chrome, and a terminal-first canvas.

Open concept ↗ 02 / HARBOR

Harbor

A light, calm workbench with a small “needs you” rail. A test of whether attention can be obvious without being loud.

Open concept ↗ 03 / ORBIT

Orbit

Project views move into a vertical tool rail, giving terminal tabs a single uninterrupted horizontal lane.

Open concept ↗ 04 / LEDGER

Ledger

A dense operations desk. Sessions become a readable vertical list; terminal output and the attention queue sit alongside it.

Open concept ↗ 05 / QUIET

Quiet

The boldest terminal-first option. Secondary controls recede until needed, but status remains visible at the bottom.

QUIET, WITH THE CONTROLS ACCOUNTED FOR

Less chrome. No lost routes.

These four follow-ups keep all seven project views and the current creation, Git, chat, Drive, project, and workspace actions reachable. Try the visible entry point in each mockup, or press ⌘ K.

06 / QUIET MENUS

Menus

The familiar version: one project-view switcher and a categorized Tools menu keep the terminal open and every action two clicks away.

Open concept ↗ 07 / QUIET DOCK

Dock

All project spaces remain visible in a slim lower dock. Global and project actions gather behind one More control.

Open concept ↗ 08 / QUIET DRAWER

Drawer

A single Workspace controls button opens a clearly grouped right drawer with views and actions, then gives the space back.

Open concept ↗ 09 / QUIET PALETTE

Palette

Search-first navigation: a visible command field and ⌘ K find any view or action without permanent toolbars.
