BENCHMARKS (run from repository root)

  node scripts/benchmark-desktop.mjs audit/desktop-2026-10-29/core-benchmark.json
  node scripts/benchmark-desktop-renderer.mjs --output audit/desktop-2026-10-29/renderer-benchmark.json
  node scripts/benchmark-desktop-package.mjs --output audit/desktop-2026-10-29/package-audit.json

Run timed workloads one at a time, after builds/tests finish. Repeat on the
same hardware with comparable host load. Report medians and individual samples;
do not compare a single sample as a guaranteed speedup. CPU ms can exceed elapsed
ms because V8 can perform concurrent work. No watts/battery measurement is made.

The launchers use installed npm dependencies (esbuild and Electron); no downloads
or global settings changes occur. The core launcher starts Electron with
ELECTRON_RUN_AS_NODE=1 and --expose-gc. Native imports match the desktop runtime.
The renderer launcher uses a hidden sandboxed Electron window and throwaway
profile; PDF.js and file IPC are mocked. Counts/retention are meaningful; mock
PDF timing is not a real-document performance measurement.

Core fixtures include real temporary SQLite databases, synthetic provider JSONL,
production replay retention invoked without constructing a live manager, and
real remote-file functions run against a fake SSH executable in a child-only
PATH. No actual SSH connection or provider archive is accessed. The metadata
probe uses actual file IO and a fake project lookup. It records the known lost-
update invariant as false rather than throwing, so inspect that field explicitly.
Temporary data is removed on normal completion and handled errors. Abrupt process
termination can leave disposable panepilot-*-benchmark/fixture temp directories.

The package script reads the existing release/mac-arm64/PanePilot.app by default.
An optional positional app path selects a different artifact. It records its own
mtime/version/hash and distinguishes logical entry bytes from filesystem
allocation. It does not build, install, sign, publish or delete an app. An existing
artifact need not match the current source; compare the recorded identity.

Rerunning overwrites JSON results but does not rewrite this dated report. Use a
different output path for comparison runs. Record the new source revision and
working-tree changes. Keep the original data with the baseline report.

BASELINE VALIDATION

Use a supported Node version for npm run build (audit used Node 22.13.0):

  npm run build

The audit's default shell Node 18.20.5 was below package.json's >=20.19.0 engine.
The command above includes typecheck. For SQLite/native-module test compatibility,
the audit ran Vitest under the installed Electron binary on macOS:

  ELECTRON_RUN_AS_NODE=1 node_modules/electron/dist/Electron.app/Contents/MacOS/Electron node_modules/vitest/vitest.mjs run --maxWorkers=2

Result: 98 files passed, 1 skipped; 539 tests passed, 2 skipped. This was the full
repository suite, including 6 Android installer tests; the audit is desktop-only.
Some existing integration tests create/clean their own exact temporary tmux
sessions. The new benchmark scripts never construct real terminal sessions.

The existing gated output benchmark was also enabled separately:

  PANEPILOT_OUTPUT_BENCHMARK=1 ELECTRON_RUN_AS_NODE=1 node_modules/electron/dist/Electron.app/Contents/MacOS/Electron node_modules/vitest/vitest.mjs run tests/terminal-output-benchmark.test.ts --maxWorkers=1

Result: 1 test passed. The other baseline skip was an optional remote fixture.

FOLLOW-UP ENERGY MEASUREMENT

Use an isolated packaged-app profile and copied/synthetic datasets. Compare idle
foreground, hidden/minimized and macOS window-closed states; then active terminal
output, many sessions on one offline host, large archives, long PDFs and split
panes. Sample the whole Electron process tree over repeated fixed windows. Record
CPU, RSS, process launches, read/write volume and wakeups. Use calibrated power
instrumentation if available and record hardware/power conditions. Never turn
these service-level CPU/IO numbers into an estimated battery-life percentage.
