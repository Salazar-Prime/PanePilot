Archive launcher pins baseline 8022d4d, bundles it through git-show without switching
the checkout, and compares it with the production worker on identical synthetic
archives. Three cold / seven warm / seven search samples; startup is separate. The worker keeps cache
memory bounded but full-text searches can reread evicted details and take longer.
The core launcher's archive section still exercises the synchronous worker engine;
use archive-comparison.json for production worker/main-loop claims.

Renderer uses actual React/layout and mocked PDF.js/preview IPC. It verifies lazy
page acquisition and renderer backing-storage retention; timings do not estimate
real PDF parsing/GPU costs. Snapshot-store benchmark uses actual byte accounting
and immutable temporary files; active decoders/base64 IPC/OS caches are excluded.

Flow uses the actual helper with an artificial delayed consumer and producer that
honors pause/resume. Its old callbacks run concurrently, so elapsed time is not a
real parser throughput comparison. Queue bytes and exact SHA-256 equality matter.
Polling uses scaled real timers and artificial latency, not real Git/SSH or hidden
Chromium timer throttling. No watts/battery-life/wakeup measurements are inferred.
